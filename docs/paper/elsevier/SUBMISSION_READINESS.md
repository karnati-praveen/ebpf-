and complete LaTeX packaging do not establish journal acceptance or erase limits

## Highest-value evidence before journal submission

1. Run fixed-horizon, remaining-work, and no-voluntary-move policies from identical initial layouts on finite cohorts and replenishing traffic separately. Include a cooldown control. Use a single frozen source snapshot and counterbalanced independent repeat blocks.
2. Run an optimized single-device baseline and a fair available-replica baseline with the same model, precision, workload, and machines. Reproduce an appropriate prior partitioning system before claiming superiority to that system.
3. Record explicit transition IDs, request admission/progress, and streamed client token times. Validate transition forecasts on held-out contexts/concurrency, with real serving outcomes as the primary endpoint.
4. Evaluate personal-chat text generation and shared inference on actual heterogeneous consumer devices. Report setup effort, memory peaks, correctness, and application-facing response metrics. The present VM workloads are deployment proxies.

The proposed ten-block planning floor in the experiment plan is not a completed
power calculation or a journal rule. Select replication from pilot variance and
a stated practically meaningful effect. An exploratory venue may accept a
narrower contribution; that is an editorial decision, not an assured outcome.
